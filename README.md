# puchi-shichigo

A Seven Little Words style puzzle game.

Branches:
- `expo` — React Native / Expo implementation
- `capacitor` — Capacitor + Vite/React implementation (future)

## Development

Start the web dev server:
```
npm run web
```

Stop it with `Ctrl+C` in the terminal. If that doesn't work, find and kill the process:
```
netstat -ano | findstr :8081
taskkill /PID <pid> /F
```
