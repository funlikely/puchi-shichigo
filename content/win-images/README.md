# Win-screen images

Drop `.png`, `.jpg`, `.jpeg`, `.webp` or `.gif` files in this folder.
When a round is solved, the win screen shows one of them at random.
If the folder is empty, the win screen shows the 🎉 emoji instead.

Everything in this folder except this README is gitignored, so your
pictures are never committed or published. After adding or removing
images, reload the app; if a new image doesn't appear, restart the
dev server with `npx expo start --clear`.
